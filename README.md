# JMU Comfort Zone

A hackathon demo concept for helping JMU students meet people, try new things, and connect with campus and the Harrisonburg community.

## Starter pages

- `index.html` — home page placeholder (reserved for the main home page work)
- `signin.html` — JMU sign-in screen
- `games.html` — short-term activities
- `projects.html` — longer-term student projects
- `game-detail.html` — activity detail and sign-up
- `project-detail.html` — project detail and join flow

These are intentionally bare HTML starting points for the team to design and build during the hackathon.
